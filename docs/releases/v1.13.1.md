# Styloagent v1.13.1

v1.13.1 supersedes the unpublished v1.13.0 draft, whose Release build was blocked by an ImageSharp license requirement.

## Changes

- Add native OpenCode v2 sessions with a private authenticated backend, an attached terminal, durable message delivery, permission replies, urgent interruption, context telemetry and park/resume recovery.
- Add DeepSeek V4.1 Flash 1017 through OpenRouter and automatic discovery of future supported Flash models. Model pickers and capabilities respect the configured provider and project overrides.
- Make Git Push, Pull, Create tag and Push tags accessible in the narrow sidebar. First push establishes branch tracking; operations retain the correct repository target.
- Fix partially staged diffs, stale history results, edited tag suggestions, concurrent Git writes and subprocess cancellation.
- Retain undelivered messages across failed sends and restarts, defer delivery while an operator is composing, and retry failed broadcast recipients individually.
- Serialize agent metadata persistence and wait for pending saves at shutdown.
- Remove Six Labors/ImageSharp from the application dependency graph. Render SVG images and exported diagrams through MIT-licensed Svg.Skia on the existing Skia 3 stack, with aligned Linux native assets. No Six Labors build key is required.
- Preserve the post-v1.12.1 Claude DeepSeek context/model mapping and archiver slug fixes.

## Verification and compatibility

- 1,177 Release-mode regression tests passed; four provider-backed C# OpenCode integration tests and 17 native shell checks passed separately on macOS arm64.
- Real UI controls pushed branches and tags to disposable Git remotes. NuGet auditing reports no known vulnerable packages across the nine solution projects.
- OpenCode requires v2; the integration was verified with **2.0.25**. Install the OpenCode executable separately and configure its provider credentials. The native instruction API is experimental.
- Windows runtime behavior and arbitrary third-party OpenCode plugins were not live-tested. OpenRouter model discovery was tested, but no paid OpenRouter generation was performed. SVG pixel regressions cover clipping, transforms, gradients, fonts, cached local images and Mermaid PNG export.

See the [integration guide](https://github.com/scottgal/styloagent/blob/v1.13.1/docs/opencode-integration.md) and [review and verification report](https://github.com/scottgal/styloagent/blob/v1.13.1/docs/code-review.md).

## Install

### macOS — getting past Gatekeeper
The app is **ad-hoc signed** (there is no paid Apple Developer ID yet), so on first launch macOS Gatekeeper will block it. Pick one:

**Option A — right-click Open (once):**
1. Unzip `styloagent-macos-<arch>.zip`.
2. **Right-click** (or Control-click) `Styloagent.app` → **Open** → click **Open** in the dialog.
3. It launches normally from then on.

**Option B — clear the quarantine flag in Terminal:**
```bash
xattr -dr com.apple.quarantine Styloagent.app
open Styloagent.app
```

> If you see **"Styloagent is damaged and can't be opened"**, that is the quarantine flag on a downloaded ad-hoc-signed app — Option B clears it. (This is expected without notarization; a signed/notarized build is a future improvement.)

### Windows
Unzip and run `Styloagent.App.exe`. SmartScreen may warn on first run (unsigned): **More info → Run anyway**.

### Linux
```bash
unzip styloagent-linux-<arch>.zip -d styloagent && cd styloagent
chmod +x Styloagent.App
./Styloagent.App
```
