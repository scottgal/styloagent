# Styloagent v1.13.5

v1.13.5 fixes repeated input alerts and keyboard focus grabs, plus approval, resume and checkpoint races across OpenCode, Codex and Claude runtimes.

## Changes

- Reconcile OpenCode attention with its current execution and latest turn. Ignore null and superseded model errors, report an unchanged current idle error once, and clear it when work resumes. Pending permissions and forms still request input.
- Report automatic OpenCode connection recovery without putting the agent into the human-input queue. Deduplicate consecutive recovery notifications and restore native state after reconnecting.
- Stop terminals from grabbing keyboard focus when attached or reattached. Explicit terminal focus and click handling remain available.
- Discard resolved Codex approval frames so ordinary command output cannot raise the same approval again; later genuine requests for the same command still work.
- Route Claude and Claude+DeepSeek resume through the common startup path, with a fresh first-paint wait for every new process. Retired processes no longer supply output or lifecycle callbacks to their replacements.
- Observe checkpoint changes before submitting the request, catching replies written during submission. The acknowledgement timeout starts after submission. Cancellation, timeout and submission failure release observation and keep the session live.

## Verification

- **1,211 Release regression tests passed:** Core 631, Git 26, App 393 and UI 161. The eight opt-in tests skipped by that run all passed separately in the two live suites below.
- **Four provider-backed integrations passed** against real OpenCode **2.0.25** and DeepSeek: authenticated MCP delivery, duplicate admission and consumption, automatic and explicit permission approval, urgent shell interruption, receipt recovery, native compaction, park/resume and crash recovery, isolated Git worktrees, and ownership rejection before mutation.
- **Four live UI/process tests passed** for late attachment, typing, model restoration, owned-process shutdown, long-session scrolling, pane replacement and startup replay overflow.
- The abrupt-parent-death probe passed: the owned OpenCode backend exits when its parent dies.
- New regressions check actual keyboard focus, error and recovery transitions, resolved approval frames, new-process readiness and fast checkpoint replies using real files. The Codex and shared lifecycle regressions failed before their fixes.

Restart Styloagent after updating to load the fixes. Validation used disposable projects and did not interrupt the running user fleet.
